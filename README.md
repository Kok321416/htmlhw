# README
## Описание выполнения заданий

В данном проекте были выполнены два задания, направленные на создание веб-страниц с использованием Bootstrap и разработку простого веб-приложения.

### Задание 1: Создание HTML-документов с использованием Bootstrap

В рамках первого задания была выполнена адаптация представленных прототипов страниц с использованием фреймворка Bootstrap. Основной целью было создание HTML-документов, которые структурно соответствуют предоставленным макетам. Следует отметить, что не требовалось точного воспроизведения страниц, но важно, чтобы они имели схожую структуру и внешний вид.

Для выполнения задания были созданы отдельные HTML-файлы, каждый из которых отображает одну из предложенных страниц. В каждом файле были подключены стили Bootstrap для обеспечения адаптивности и современного дизайна.

### Задание 2: Создание простого веб-приложения для обработки GET-запросов

На основе получившейся разметки было разработано простое веб-приложение. Главной функциональностью приложения является возврат страницы «Контакты» на любой GET-запрос. Для корректного функционирования приложения необходимо, чтобы все файлы подключения были загружены из удаленного репозитория.

В этом задании было осуществлено следующее:

- Сервер был настроен так, чтобы на все GET-запросы возвращалась статическая HTML-страница.
- Для изменения типа данных ответа был заменен заголовок Content-type с application/json на text/html, что позволило серверу отправлять HTML-контент.
- В коде была использована конструкция with open(), чтобы прочитать содержимое HTML-файла и отправить его в качестве ответа на запрос. 
- спасибо за обучение!
